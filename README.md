# HR-Analytics-Dashboard-PowerBI

## Project Overview
This project analyzes employee attrition trends, workforce demographics, and job satisfaction using Power BI.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Dataset
The dashboard is built using employee workforce data containing demographic, education, department, and attrition information.

## Key KPIs
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Employee Age

## Dashboard Features
- Department-wise Attrition Analysis
- Employee Distribution by Age Group
- Job Satisfaction Analysis
- Gender-based Attrition Insights
- Education Level Filters
- Interactive Visualizations

## Business Insights
- Identify departments with higher attrition.
- Analyze workforce demographics.
- Understand employee satisfaction trends.
- Support HR retention strategies.
